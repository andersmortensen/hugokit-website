The first release of HugoKit.

## New

- Add individual Hugo sites or scan a parent folder for projects.
- Start and stop Hugo's server and change draft, future and expired content settings.
- View parsed build logs and the exact Hugo command.
- Publish to GitHub Pages, FTP or SFTP, with one or more targets per site.
- Run Preflight before publishing to check links, subpaths, configuration and assets. Suggested fixes are shown as diffs.
- Create sites from the HugoKit Starter or Hugo's blank template, with optional Git setup.
- Open Site Health with `⇧⌘H` to see the score, checks, content statistics and build trend.
- Open Template Preview with `⇧⌘T` to render a layout against the site.
- View page, section and word counts with front matter checks.
- Edit the Hugo config as fields or raw text and review the diff before saving.
- Search the Hugo Reference from a separate app window.
- Control servers from the menu bar and use shortcuts for Publish, Preflight, Site Health and Template Preview.
- HugoKit finds an existing Hugo installation or offers to install Hugo Extended.

## Notes

- Free to use. No account is required, and deploy credentials are stored in Keychain.
- Requires macOS 26 (Tahoe) or later
