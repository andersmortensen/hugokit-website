0.2.0 adds snapshots and per-file diffs to every file change made by HugoKit.

## New

- **Snapshots:** HugoKit copies a file before changing it. If the snapshot fails, the file is not changed.
- **Per-file diffs:** the Snapshots sheet shows the diff recorded for each changed file.
- **Two-level undo:** restore one file or every file in an operation. A restore creates a new snapshot first.
- **Per-site snapshot settings:** enable or disable snapshots and set the number of versions kept per file.
- **Front matter inspector:** edit title, description, date, draft, tags and categories beside the file. Suggestions come from the site's existing taxonomies, and unchanged fields keep their formatting.
- **Taxonomy overview:** view tags and categories across the site, find spelling variants and rename a value in every affected file as one snapshot.
- **Git URL import:** clone a repository and add the site from the same dialog. GitHub tokens are attached only to `github.com` URLs.
- **Archive a site:** hide a site from the sidebar and counts without changing its files. Archived sites can be restored from Settings.
- **Sidebar groups:** organise sites in collapsible groups.
- **Build flags per site:** configure garbage collection, minification and the Hugo environment, with the resulting command shown on Deploy.
- **Publish to All Targets:** publish to every active target from one button.
- **Per-target status:** each deploy target has its own status and history.
- **Target health:** HugoKit checks the public URL after a successful publish. **Check if Live** runs the same check on demand.
- **Git state on Deploy:** the Deploy page shows uncommitted changes, the current branch and whether `origin` matches the configured repository.
- **Deprecation inbox:** the dashboard groups repeated Hugo deprecation notices and shows their counts.
- **Copy Diagnostics:** the Help menu creates a sanitised report with app, Hugo and macOS versions, relevant settings and the latest log. Credentials and personal paths are excluded.
- **Crash reports:** a crash is shown as a readable report on the next launch. The report is not sent automatically.

## Improved

- **Page bundles:** a leaf bundle appears as one content entry, with its resources listed as thumbnails.
- **Parallel publishing:** active targets build to separate folders and upload in parallel, with a result for each target.
- **Automatic `lastmod`:** saving updates an existing `lastmod` field. The field is not added to pages that do not use it.
- **Starter template:** adds an archive, colophon, sidenotes, timeline view, `⌘K` search, per-page sharing images and `llms.txt`.
- **Redesigned window:** the sidebar and content now use separate panes on one background.
- **Background surface:** choose Flat, Warm Gradient, Quartet or Liquid Glass in Settings.

## Fixed

- **Dotfiles:** FTP/SFTP publishing now includes `.htaccess`, `.well-known` and `.nojekyll`. Finder metadata remains excluded.
- **Symlinked paths:** FTP smart sync now handles project paths reached through a symlink.
- **GitHub sign-in:** the authorisation dialog now names HugoKit instead of the project's former name.
- **Config diffs:** Review Changes no longer marks untouched string fields as changed after editing one field.
- **Template Preview:** `single.html` previews no longer enter a redirect loop when the URL needs a trailing slash.

## Notes

- **Requirements:** macOS 26 (Tahoe) or later
