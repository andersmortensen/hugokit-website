0.5.0 adds Split Preview, page duplication, reusable archetypes, a media library, translation drafts and batch editing. Content search now includes page text.

## New

- **Split Preview:** edit Raw beside the actual Hugo-rendered page. Save updates the preview after Hugo rebuilds. Front Matter can be shown or hidden alongside the editor.
- **Duplicate Page:** create an independent draft from an existing page, with a fresh date and cleared URL and publication settings. Bundle resources can be copied with it.
- **Save as Archetype:** turn a page into a reusable Hugo content template. Choose front matter fields, edit the template body and optionally include bundle files.
- **Media Library:** browse images, audio, video and PDFs from content, static and assets, with Quick Look. Copy a file into the current bundle or static/media and insert its reference.
- **Create Translation:** create a draft for a missing language using the site’s filename convention. The source text is copied for you to translate; existing pages are preserved.
- **Batch Edit:** select pages to add or remove tags and change draft status. Review the complete diff before applying the changes, protected by one recovery snapshot.
- **Publication dates:** edit publishDate and expiryDate in Front Matter. Published, Scheduled and Expired statuses follow Hugo’s effective dates and configuration.

## Improved

- **Full-text search:** find saved page text as well as titles, sections and paths. Results show an excerpt and line number; opening a result selects the matching text in Raw.
- **Backlink navigation:** click a Linked from entry to open the source at the link’s line, with Save, Discard or Cancel for unsaved edits.
- **Hugo installation:** supports macOS .pkg packages alongside older .tar.gz archives.

## Fixed

- Newly created pages and bundles now open directly in Raw.
- A port conflict no longer attaches a site to a server belonging to another project.

## Notes

- Duplicate Page and Create Translation support Markdown files. Translation drafts use filename-based languages in a shared content folder.
- Media insertion for regular pages requires a saved page and a standard static directory. Custom static mounts and multihost setups are not supported.
- Servers started outside HugoKit use manual Refresh in Split Preview.
- Requires macOS 26 (Tahoe) or later.
