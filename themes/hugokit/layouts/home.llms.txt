# {{ site.Title }}

> HugoKit is a macOS app that runs Hugo projects from a native interface. It starts the local server, edits content and configuration, checks the built site, and publishes to GitHub Pages, FTP or SFTP. It works with the Markdown files and Hugo configuration already in the project.

- Download: free
- Requires macOS 26 (Tahoe) or later
- Account: not required
- Maintained by Anders Mortensen in Denmark
